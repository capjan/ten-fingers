# Datenschutz in der macOS-App Ten Fingers

## Datenschutzerklärung

Ich nehme Datenschutz und Privatsphäre ernst! In meiner macOS-App Ten Fingers erfasse ich keinerlei persönliche Informationen, weder direkt noch indirekt.

## Datenerhebung und -verwendung

Die macOS-App Ten Fingers erfasst keine personenbezogenen Daten wie Namen, E-Mail-Adressen, Standortdaten oder andere persönliche Informationen.

## Tracking

Die App Ten Fingers verwendet keine Tracking-Technologien zur Erfassung von Nutzeraktivitäten.

## Datenweitergabe an Dritte

Da ich keine personenbezogenen Daten erfasse, gibt es nichts, das weitergegeben werden könnte. Damit ist absolute Sicherheit gewährleistet.

## Kontakt

Wenn Sie Fragen oder Bedenken bezüglich unserer Datenschutzpraktiken haben, erreichen Sie mich unter [privacy@tenfingers.app](mailto:privacy@tenfingers.app).

Diese Datenschutzerklärung kann gelegentlich aktualisiert werden, um Änderungen unserer Datenschutzpraktiken widerzuspiegeln. Die aktuelle Version finden sie unter www.tenfingers.app/datenschutz-macOS
