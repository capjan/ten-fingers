# Website review and screenshot notes

## Design decisions

- Lead with the purpose of the app, a direct Mac App Store link, and a real product screenshot.
- Explain the same three-step workflow in German and English: choose a lesson, practise with keyboard hints, review results.
- Replace decorative illustrations and developer-facing Xcode captures with current product views. Privacy and distribution claims are explained in text.
- Keep the existing page URLs and the local MDU workflow. Use built-in navigation and theme handling rather than introducing another site framework. Move legal links into a consistent footer so they do not create a documentation sidebar on desktop.
- Make support actionable and describe the independent developer in a short, personal About page.
- Remove unqualified security guarantees and speculative platform plans. Preserve contact information and the substance of the privacy notices.

## Screenshot provenance

App source: `tenfingers`, commit `c2573acfd95f039125b9d91e258a5e027f2c4841`, version 1.16.0 (23), built locally on 6 November 2026 with Xcode.

The German `TenFinger` and English `TenTypingFingers` schemes both built successfully. English capture uses a temporary copy of the built app with German resource localizations excluded and a separate capture bundle identifier. Application source code is unchanged, and the capture copy is signed with the existing development identity and retains the app sandbox.

German results show an existing completed session. English results are generated by entering a practice lesson in the isolated capture app. Training values illustrate the interface and are not performance promises.

Final assets: three Light/Dark scene pairs per language, plus a shorter German homepage overview pair. The training images are focused crops showing the hands, practice text, and keyboard; the metrics remain visible in the separate results scene. Only the top 30 pixels of capture chrome are removed from full-window images.

Capture each scene in both appearances. Keep the same state, window size, and framing within each light/dark pair. Preserve the real UI and colours; do not recolour or reconstruct screenshots. Remove only capture chrome and unnecessary outer whitespace when cropping for the website.

| Scene | Acceptance criteria |

| Active practice | Exercise text, highlighted key, and finger-zone guidance visible together. |
